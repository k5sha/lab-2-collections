# Лабораторна робота №2 (Gradle & Java Collections Framework )

## Опис проєкту

Загалом реалізовано частотний аналізатор тексту з використанням Java Collections Framework. 
Основний функціонал зосереджено в класі `WordCounter`, який забезпечує підрахунок кількості входжень кожного слова у вигляді мапи `Map<String, Integer>` та пошук усіх унікальних слів у вигляді сету `Set`. 
Обробка тексту здійснюється шляхом розбиття рядків за регулярним виразом `[^a-zA-Z0-9]+` з  приведенням слів до нижнього регістру та ігноруванням порожніх елементів і null-рядків. Залежностями в проєкті керує `Gradle`.
Також написано юніт-тести на `JUnit 5`, які перевіряють усі сценарії поведінки програми.

## Розрахунок варіанта

$$V = 5 \bmod 3 = 2$$

**Варіант $V = 2$:** Частотний аналізатор тексту

## Інструкція із запуску та тестування

> Для збірки проєкту та виконання тестів потрібна встановлена JDK 21+

Запуск повної збірки проєкту:

```bash
./gradlew build
```

Запуск юніт-тестів:

```bash
./gradlew test
```
